# 裏ハルキュー：LOW別3-2-2決着型をブラックボックスにしないための全16型公開（2026-10-25）

研究成果の説明資料。実装、既存モデル、固定2-2-2-1、購入ルール、Webの変更を行わない。購入未承認。

## 1. 役割と買い目の定義

- 3H = 3車ライン先頭、3B = 3車ライン番手、3T = 3車ライン3番手。
- 2H = 2車ライン先頭、2B = 2車ライン番手。2車ラインは2組で交換可能。強さ順位が大きい方を固定して選ぶ意味ではない。
- |12 = 1・2着が同ライン、3着は異線、|23 = 2・3着同ラインで1着異線、|13 = 1・3着同ラインで2着異線。
- 型は1着→2着→3着の順で並べる。例えば 2H-3H-3B|23 とは「2車ライン先頭が1着、3車ライン先頭が2着、同3車番手が3着」。
- 仮想ライン①-③-⑤／②-⑥／④-⑦なら、2H-3H-3B|23 は ②-①-③ および ④-①-③。固定裏AIの7車評価5〜7位を含む券だけ候補にし、同じ車番は重複させない。
- LOW = 固定裏AIによる上位2名の評価差。区間は [0,0.25)、[0.25,0.5)、[0.5,0.75)、[0.75,1)。LOWの外は今回対象外。
- どの型でも全該当3連単に各100円。投資額は購入点数×100円、払戻は的中時の公式3連単確定払戻。確定オッズは型選別に使わない。

## 2. どうしてこの16型を選んだのか

2023年の各LOW区間で的中数2以上を持つ決着位置構造を単独ROIで降順並べ、上位12を候補とした。2024年にも2的中以上ある候補について、2023 ROIと2024 ROIの低い方を評価値として降順並べた。その上位4型ずつ、計16型にした。2025年・2026年の結果は選定に使用しない。

**注意：この手順は「組み合わせそのものの最適化」ではない。各型を単独評価順に足しているに過ぎない。** 年間2的中という基準は弱すぎる可能性が高く、単独ROI100%未満、特に2024年の回収率40%前後を示す型も4位まで機械的に入っている。これは「単独で黒字に近い型を複数持つ」というユーザー方針を十分実装したものではない。

同一LOW区間・同一年の異なる構造型は重複券を含まず、各100円購入なら合成ROIは各単独ROIの**投資額加重平均**。単独マイナス型を足すだけで黒字を生成することはできない。ただし的中カバーと損益変動は変化する。

## 6. 何を調べていないか／誤って説明すべきでないこと

今回実際に測ったのは、決着位置構造、LOW帯、適格購入点数、的中、確定払戻、区間別の過去年数である。弱いラインの正しい強度、ラインの先頭・番手の脚質、選手年齢、直近状態、発走前オッズ、市場期待値、バンク、他型との的中相関を因果的に学習したわけではない。「上位4型」に市場優位や将来再現性がある証明はない。過去の元ハルキューの歴史的特徴量に事後混入や学習期間重複の可能性があるため、これはそのまま買える検証でもない。
